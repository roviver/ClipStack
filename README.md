# clipstack

Менеджер буфера обмена для macOS. Живёт в меню-баре, помнит историю копий, вставляет
выбранное прямо в активное окно.

## Установка

```bash
./Scripts/make-cert.sh
./Scripts/make-icon.sh
./Scripts/install.sh
```

Первый скрипт создаёт самоподписанный сертификат — без него разрешение Универсального
доступа будет слетать после каждой пересборки. Достаточно один раз.

После первой попытки вставить элемент macOS попросит выдать Универсальный доступ:
**Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**.
Без него всё работает, кроме автовставки — элемент просто ложится в буфер.

## Как пользоваться

| Действие | Клавиши |
| --- | --- |
| Показать историю | ⇧⌘V (меняется в настройках) |
| Выбрать и вставить | ↑ ↓, затем ↩ |
| Взять одну из первых девяти | ⌘1 … ⌘9 |
| Прыгнуть на десять строк | Page Up / Page Down |
| Закрепить или открепить | ⌘P |
| Удалить запись | ⌘⌫ |
| Закрыть панель | Esc |

Поиск — просто начни печатать, поле уже в фокусе. Фильтры под поиском отбирают по типу
(текст, ссылки, картинки, файлы, цвета) и показывают закреплённые.

Закреплённые записи не вытесняются при переполнении истории и в лимит не входят.

## Что хранится и где

`~/Library/Application Support/clipstack/` — база SQLite и картинки. Всё лежит только на
этом компьютере и никуда не отправляется.

Копии, помеченные приложением как секретные (так делают менеджеры паролей), не сохраняются
никогда. Отдельные приложения можно занести в игнор-лист в настройках.

## Ограничения

* Хранится только текст без форматирования — RTF и HTML теряются.
* Синхронизации с iPhone нет: она требует платного Apple Developer Program.
* На MacBook с чёлкой иконка может оказаться под вырезом, если меню-бар плотно занят.
  Перетащи её с зажатым ⌘ — новое место запомнится.
